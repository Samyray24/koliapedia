**Коляпедия** — шуточное интерактивное приложение и энциклопедия, посвященная Николаю, каламбурам про Колю и хорошему настроению. Приложение работает как нативное десктопное приложение Windows (`Коляпедия.exe`) и как адаптивное веб-приложение.

---

## 🌟 Основные возможности

### 📖 1. Энциклопедия «Коляпедия» (35+ каламбуров)
Фундаментальный реестр юмористических понятий с «научной классификацией», характеристиками (харизма, опасность, уровень Коли), цитатами и эффектами:
* 🥤 **Кока-Коля** — 0% сахара, 100% отборного Николая. Праздник к нам приходит!
* 🤣 **Колики в животике** — спазм пресса от искрометного юмора.
* 😍 **Коляфил** — человек с тягой называть всех котов и Wi-Fi сети Николаями.
* 🍹 **Пино-Коляда** — тропический чилл в гавайской рубашке с зонтиком.
* 🍫 **Шо-Коляд** — 85% отборного какао и харизмы, тает прямо в сердечке.
* ⚛️ **Большой Адронный Коляйдер** — разгон Коли в пятницу до скорости света.
* 🌧️ **Мелан-Коля** — глубокий мыслитель у осеннего окна с чашкой чая.
* ✨ **Коля-ген** — секретный белок вечной молодости и бодрости.
* 🥦 **Бро-Коли** — самый верный и питательный овощ-друг.
* 🍕 **Коля-цоне** — итальянская закрытая пицца с Колей внутри.
* ☕ **Коля-чино** — бодрящий утренний кофе с короной из пенки.
* 🕶️ **Терминатор-Коля** — «I will be Kolya!» спаситель от скучных будней.
* 🧙 **Гарри Коля** — мальчик, который выпил всю Кока-Колю.
* 🏎️ **Формула-Коля** — болид с двигателем на 1000 лошадиных сил харизмы.
* 💎 **Коля-рат** — 24-каратный чистейший Николай без примесей.
* 📜 **Прото-Коля**, 🌀 **Коляпсус**, ⚡ **Николь-а-Тесла**, 🦖 **Коля-завр** и многие другие!

---

### 🎮 2. Коля-Игротека (6 мини-игр)
1. **🥤 Коля-Раннер** — динамичная аркада: ловите баночки Кока-Коли, Пино-Коляду и Бро-Коли, уворачивайтесь от будильников и Коляпсусов.
2. **🐦 Коля-Флаппи** — полёт сквозь трубы-будильники и дедлайны на HTML5 Canvas физике.
3. **🧠 Коля-Мемори** — логическая игра на память: поиск пар карточек на время с фиксацией рекорда.
4. **💣 Коля-Сапёр** — логическая головоломка: обезвреживание скрытых аномалий-Коляпсусов с установкой флажков.
5. **⚡ Фабрика Коля-гена** — кликер с магазином автоматических улучшений (курьер Бро-Коли, бармен Пино-Коляды, Адронный реактор).
6. **🎨 Мем-Студия** — генератор авторских мемов про Колю с выбором шаблонов, стикеров и скачиванием готовой PNG-картинки.

---

### 🎯 3. Интерактивные модули
* **Коля Дня** — анимированная рулетка судьбы с конфетти.
* **Тест личности** — квиз «Какой ты Коля сегодня?».
* **Коляриметр** — био-спектрометр уровня Коли в крови по любому введенному имени.
* **Генератор тостов** — праздничные поздравления для Коли по поводам.
* **Коля-Саундборд** — звуковая панель (пшик газировки, разгон Коляйдера, победные фанфары на Web Audio API).

## 💻 Установка и запуск

### 1. Запуск нативного Windows-приложения:
Дважды кликните по файлу:
```
Коляпедия.exe
```
(или по ярлыку **«Коляпедия»** на Рабочем столе Windows).

### 2. Запуск в браузере (для разработки):
```bash
# Установка зависимостей
npm install

# Запуск локального dev-сервера
npm run dev
```
Откройте в браузере: `http://localhost:5173/`

### 3. Сборка проекта:
```bash
npm run build
```

## ⌨️ Горячие клавиши на ПК
* `1` ... `7` — переключение между разделами
* `Ctrl + K` — быстрый глобальный поиск
* `M` — тумблер звука
* `F11` или кнопка ⛶ — полноэкранный режим игры
