# 🧠 Полная Библиотека из 100 Скилов для ИИ-Агентов и Разработчиков
### Совместимо с: **Google Antigravity**, **OpenAI Codex**, **Claude Code**, **Cursor**, **Windsurf**

Каталог содержит **100 профессиональных стандартов и процедур («скилов» / runbooks)** для автономных ИИ-ассистентов и инженеров. Каждый скил оформлен в стандарте Markdown с метаданными YAML и содержит архитектурные правила, шаблоны кода и чеклисты.

## 🛠️ Как использовать в Codex / Claude / Cursor
Любой ИИ-ассистент может напрямую прочитать файл нужного скила по пути:
```
skills/<имя-скила>/SKILL.md
```
или руководство по подключению в [`CODEX.md`](../CODEX.md).
